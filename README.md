# Student Management System

A Python-based Student Management System built using modular programming and JSON data storage.

## Features

- Add Student
- View Students
- Update Student Information
- Delete Student Records
- JSON Data Persistence
- Modular Project Structure

## Technologies Used

- Python
- JSON
- File Handling
- Modular Programming

## Project Structure

main.py - Main menu

student_logic_file.py - Student operations

data_handle.py - JSON read/write operations

students.json - Database file
